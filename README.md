# Water Pollution Intelligence - AI-Powered Water Contamination Detection

Water Pollution Intelligence detects and analyzes water pollution using a YOLOv8 object detection model. It combines a FastAPI backend with a Streamlit dashboard and a multi-agent pipeline for classification and reporting.

Features:
- YOLOv8 Object Detection
- - Multi-Agent Analysis Pipeline
  - - Interactive Dashboard (Streamlit)
    - - FastAPI Backend
      - - Contamination Classification
        - - Confidence Scoring
          - - Visual Result Overlays
           
            - Tech Stack:
            - Python, FastAPI, Streamlit, YOLOv8, OpenCV, Pillow
           
            - Installation:
            - 1. git clone https://github.com/GopeshKachhadiya/Water-Pollution-detection-Model.git
              2. 2. pip install -r requirements.txt
                 3. 3. Start FastAPI: uvicorn app:app --port 8000
                    4. 4. Start Streamlit: streamlit run frontend.py
